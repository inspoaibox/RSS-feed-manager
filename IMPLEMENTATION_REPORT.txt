✅ 功能 1：翻译范围选择
   目标：降低翻译成本，允许用户选择只翻译标题或标题+正文
   
   实现细节：
   • 数据库新增字段：translate_title, translate_content
   • 后端翻译逻辑：根据配置过滤翻译内容
   • 前端 UI：订阅源编辑时显示翻译范围复选框
   • 数据验证：至少需要选择一项
   
   预期收益：
   • 翻译字符消耗 ↓ 70-90%
   • 翻译速度     ↑ 50-80%
   • API 成本     ↓ 70-90%
   • 服务器负载   ↓ 30-50%

✅ 功能 2：Worker 配置管理
   目标：允许管理员在后台动态调整 Worker 配置参数
   
   实现细节：
   • 数据库存储：system_settings 表保存配置
   • 后端 API：GET/PUT /api/system/settings
   • 前端 UI：系统设置 -> 任务队列页签
   • 可配置项：
     - 普通 Worker：并发数、子进程任务数、CPU 限额
     - 浏览器 Worker：并发数、子进程任务数、CPU 限额
   
   使用流程：
   1. 后台修改配置并保存
   2. SSH 执行重启命令
   3. 配置生效

📊 配置建议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

根据服务器规格的 Worker 配置建议：

┌──────────┬──────────────┬──────────┬──────────────────┬──────────┐
│ 服务器   │ 普通Worker   │ CPU限额  │ 浏览器Worker     │ CPU限额  │
│ 规格     │ 并发数       │          │ 并发数           │          │
├──────────┼──────────────┼──────────┼──────────────────┼──────────┤
│ 1核2G    │ 1            │ 0.8      │ 1                │ 0.5      │
│ 2核4G    │ 2            │ 1.5      │ 2                │ 1.0      │
│ 4核8G    │ 3            │ 2.0      │ 3                │ 2.0      │
│ 8核16G   │ 5            │ 4.0      │ 5                │ 3.0      │
└──────────┴──────────────┴──────────┴──────────────────┴──────────┘

注意：
• CPU 限额 0 表示不限制
• 浏览器 Worker 消耗内存较多，建议并发数不超过 5
• 子进程任务数默认 20 对大多数场景适用
