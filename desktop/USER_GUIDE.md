# RSS Manager 桌面版 - 用户指南

## 安装

1. 下载 `RSSManager-Setup-1.0.0.exe`
2. 双击运行安装程序
3. 按照向导完成安装
4. 从开始菜单或桌面快捷方式启动应用

## 首次使用

### 启动应用

- 双击桌面图标或从开始菜单启动
- 应用会自动打开主窗口
- 首次启动会自动初始化数据库

### 数据存储位置

所有数据存储在：
```
%APPDATA%\RSSManager\
```

包含：
- `rss_manager.db` - 数据库文件
- 日志文件
- 临时文件

## 主要功能

### 1. 添加订阅源

1. 点击左侧「订阅源」
2. 点击「添加订阅」按钮
3. 输入 RSS/Atom 订阅地址
4. 设置分类和同步间隔
5. 点击「保存」

### 2. 阅读文章

1. 在订阅源列表中选择一个源
2. 右侧显示该源的文章列表
3. 点击文章标题查看详情
4. 可以标记为已读、收藏

### 3. 分类管理

1. 点击「分类管理」
2. 创建新分类
3. 将订阅源拖动到分类中

### 4. 自定义抓取规则

对于不提供 RSS 的网站：

1. 点击「自定义规则」
2. 创建新规则
3. 配置 CSS 选择器
4. 设置抓取间隔

### 5. AI 功能

#### 配置 AI 服务

1. 点击「设置」
2. 选择「AI 设置」
3. 添加 AI 渠道（OpenAI/Gemini）
4. 输入 API Key
5. 保存配置

#### 自动翻译

1. 在文章详情页
2. 点击「翻译」按钮
3. AI 会自动翻译文章内容

#### 自动摘要

1. 在文章详情页
2. 点击「摘要」按钮
3. AI 会生成文章摘要

#### AI 分析（关键词搜索）

桌面版使用关键词搜索（不支持语义搜索）：

1. 点击「AI 分析」
2. 输入搜索关键词
3. 查看匹配的文章

### 6. 定时同步

应用会自动在后台同步订阅源：

- 根据每个源设置的间隔自动抓取
- 可以在订阅源设置中修改间隔（1分钟 - 24小时）
- 手动刷新：点击订阅源旁的刷新按钮

### 7. 备份与恢复

#### 导出 OPML

1. 点击「设置」→「备份」
2. 点击「导出 OPML」
3. 选择保存位置

#### 导入 OPML

1. 点击「设置」→「备份」
2. 点击「导入 OPML」
3. 选择 OPML 文件

#### WebDAV 备份

1. 配置 WebDAV 服务器信息
2. 点击「备份到 WebDAV」
3. 自动上传配置和数据

## 高级功能

### Playwright 浏览器模式

对于有 Cloudflare 保护的网站：

1. 编辑订阅源
2. 启用「使用浏览器模式」
3. 保存后重新抓取

### 通知管理

1. 点击右上角通知图标
2. 查看系统通知
3. 标记为已读

### 推荐订阅源

1. 点击「发现」
2. 浏览推荐的订阅源
3. 一键订阅

## 常见问题

### 1. 应用无法启动

**解决方法**：
- 检查是否有其他实例正在运行
- 删除 `%APPDATA%\RSSManager\` 目录重新初始化
- 以管理员身份运行

### 2. 订阅源抓取失败

**可能原因**：
- 网络连接问题
- RSS 地址无效
- 网站需要浏览器模式

**解决方法**：
- 检查网络连接
- 验证 RSS 地址
- 启用浏览器模式

### 3. AI 功能不可用

**解决方法**：
- 检查 AI 配置是否正确
- 验证 API Key 是否有效
- 检查网络连接

### 4. 数据丢失

**预防措施**：
- 定期导出 OPML
- 使用 WebDAV 自动备份
- 手动备份 `%APPDATA%\RSSManager\` 目录

### 5. 应用运行缓慢

**优化建议**：
- 减少订阅源数量
- 增加同步间隔
- 清理旧文章（自动清理 90 天前的非收藏文章）

## 卸载

### 方式一：使用卸载程序

1. 打开「控制面板」→「程序和功能」
2. 找到「RSS Manager」
3. 点击「卸载」

### 方式二：从开始菜单

1. 打开开始菜单
2. 找到「RSS Manager」文件夹
3. 点击「卸载 RSS Manager」

### 清理数据

卸载后，如需完全清理：

删除目录：
```
%APPDATA%\RSSManager\
```

## 更新

### 检查更新

应用会自动检查更新（如果启用）

### 手动更新

1. 下载最新版安装程序
2. 运行安装程序
3. 选择「升级」
4. 数据会自动保留
